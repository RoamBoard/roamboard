# RoamFlow gallery photography

## Image workflow for coding agents

Read [the supported image workflow](../../../../docs/IMAGE_WORKFLOW.md) before adding or changing images. Raster page photography now uses database-backed `library:` references through the shared image components. These original files remain migration/rollback fallbacks and retain the source credits below. SVG icons and masks stay local. Register new supplied images with `images:add`, verify the saved record, and wire the returned key into the page; do not introduce unregistered image URLs. Protected Board/activity uploads keep their separate authenticated upload and ordering flow.

These eighteen photos reuse the original Figma image fills documented in
[`../board-cards/README.md`](../board-cards/README.md). They are larger copies of the V1 collage photographs,
prepared from the original exports for V4's full-card image slots. Existing small collage assets are unchanged.

The images retain their source aspect ratios and use WebP at quality 88, with a maximum size of 1000 × 1500 pixels.
Cropping remains the shared Board V4 component's responsibility. No complete card screenshots are used as assets.

The gallery also reuses the three V4 and three V3 photographs directly, plus four existing Tokyo viewer photos.
Editorial stories and authors in the preview collection are fictional; these files do not represent persisted Boards.
